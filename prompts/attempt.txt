You are a **smoking quit-attempt extractor** analyzing a tobacco-cessation counseling conversation.

CONVERSATION:
{conversation}

Your task is to identify all **prior quit attempts** mentioned by the **patient**.

A **quit attempt** is any instance where the patient **intentionally tried to stop or reduce smoking**, regardless of success or duration.

This includes:

* Stopping abruptly (e.g., cold turkey)
* Using aids (nicotine patch, gum, medication, vaping to quit, etc.)
* Gradually reducing smoking with the intention to quit
* Temporary abstinence (even for a short period such as hours, days, or weeks)
* Any structured or unstructured effort (self-initiated or guided)

Do NOT include:

* General thoughts, desires, or intentions to quit without action
* Future plans to quit
* Hypothetical or vague statements without an actual attempt

For each valid quit attempt, extract:

* Method used (if not mentioned, use "unknown")
* Duration (if not mentioned, use "unknown")
* Reason for relapse or stopping (if not mentioned, use "unknown")

Represent each attempt as a **single concise natural-language description**.

Also extract **evidence**:

* Provide an exact quote or a close paraphrase from the conversation that supports each attempt
* Evidence must correspond to the same order as the attempts

Additional rules:

* Focus only on statements made by the patient, not the counselor
* Do not infer missing details; use "unknown" when necessary
* If multiple attempts are mentioned in a single sentence, separate them into distinct attempts
* If no attempts are found, return empty lists

Output strictly in valid JSON with the following schema:

{{
"attempts": ["<attempt description 1>", "<attempt description 2>"],
"evidence": ["<supporting quote/paraphrase 1>", "<supporting quote/paraphrase 2>"]
}}
